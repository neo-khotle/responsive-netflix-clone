# Responsive-Netflix-Clone

A responsive Netflix landing page clone built using HTML5 and CSS3. This project recreates the look and feel of Netflix's homepage, focusing on responsive web design, layout styling, and user interface development.

🌐 Live Demo

[View Live Project](https://neokhotle-netstream.netlify.app/)

📌 Project Overview

This project is a front-end recreation of the Netflix landing page. It features a dark-themed interface, promotional hero section, trending movie collections, membership benefits, and a frequently asked questions section.

The main goal was to practise building a responsive website from scratch while improving my understanding of HTML structure, CSS styling, Flexbox, CSS Grid, and media queries.

✨ Features

Responsive Navigation: Netflix-inspired navigation bar with logo and Sign In button.

Hero Section: Full-screen background image with a promotional heading and email signup form.

Trending Now: Horizontally scrollable movie and TV show collections with numbered rankings.

Embedded Video: Responsive video section featuring a trailer.

Reasons to Join: Feature cards highlighting Netflix membership benefits.

Interactive FAQ Section: Expandable and collapsible questions using HTML <details> and <summary> elements.

Email Signup Forms: Styled email input fields and call-to-action buttons.

Footer Navigation: Multiple navigation links and language selection.

Responsive Layout: Adaptable layouts for mobile, tablet, desktop, and larger screens.

🛠️ Technologies Used

HTML5 – Semantic structure and content organisation.

CSS3 – Styling, typography, gradients, backgrounds, and visual effects.

CSS Flexbox – Flexible layouts and element alignment.

CSS Grid – Responsive card layouts and footer navigation.

CSS Media Queries – Responsive breakpoints for different screen sizes.

Google Fonts – Roboto typography.

YouTube Embed – Integrated video content.

📱 Responsive Design

The project follows a mobile-first approach, using CSS media queries to adapt the layout to different screen sizes.

Device

Breakpoint

Mobile

0px – 767px

Tablet

768px – 1023px

Desktop

1024px and above

Large Desktop

1280px and above

Full-screen displays

1600px and above
